激活函数汇总

输出范围、优缺点，以及 PyTorch 里对应的层。

zyzhou29 Sep 2026约 1100 字3 min read

Sigmoid

Sigmoid 是早期神经网络最常用的激活函数之一，它将任意实数映射到 (0, 1) 区间内。

$$f(x) = \frac{1}{1+e^{-x}}$$
  • 输出范围 (0, 1)。由于输出在这个区间，它常被用作二分类任务的输出层，表示属于正类的概率。
  • 优点：平滑且易于求导。
  • 缺点：
    1. 梯度消失。当输入 𝑥 非常大或非常小（趋于正负无穷）时，函数的梯度几乎为 0。这会导致反向传播时，深层网络的参数无法有效更新。
    2. 非零中心化。输出全为正数，这会导致优化过程中梯度更新出现「Z」字型的震荡，收敛变慢。
    3. 计算成本相对较高。
import torch.nn as nn
sigmoid = nn.Sigmoid()

Softmax

Softmax 通常用于多分类神经网络的输出层。它可以看作是 Sigmoid 在多分类问题上的推广。对一个包含 𝐾 个元素的向量 𝑧，Softmax 将第 𝑖 个元素转换为：

$$f(z_i) = \frac{e^{z_i}}{\sum_{j=1}^{K} e^{z_j}}$$
  • 输出范围 (0, 1)，并且所有输出元素的总和为 1。
  • 优点：能够将模型的原始输出（logits）转化为直观的概率分布，非常适合多分类任务。
  • 注意：通常直接使用 nn.CrossEntropyLoss()。它内部已经包含了对数 Softmax 操作，因此无需在网络最后一层手动添加 Softmax。
import torch.nn as nn
# dim=1 表示在特征维度（即类别维度）上进行 Softmax 计算
softmax = nn.Softmax(dim=1)

Tanh

Tanh 函数的形状和 Sigmoid 很像，也是一个 S 型曲线，但它是零中心化的。

$$f(x) = \frac{e^{x}-e^{-x}}{e^{x}+e^{-x}}$$
  • 输出范围 (−1, 1)。
  • 优点：解决了 Sigmoid 非零中心化的问题，因此在隐藏层中，Tanh 通常比 Sigmoid 表现更好，网络收敛速度更快。
  • 缺点：仍然没有解决梯度消失的问题。当输入值很大或很小时，梯度依然会趋近于 0。
import torch.nn as nn
tanh = nn.Tanh()

ReLU

ReLU（修正线性单元）是目前深度学习中最流行的隐藏层激活函数。

$$f(x) = \max(0, x)$$
  • 输出范围 [0, +∞)。当输入为正数时，原样输出；当输入为负数时，输出为 0。
  • 优点：
    1. 解决了正区间梯度消失问题。当 𝑥 > 0 时，梯度恒为 1，使得深层网络更容易训练。
    2. 计算速度极快。只涉及简单的阈值判断，没有指数运算。
    3. 稀疏性。使得一部分神经元输出为 0，这在一定程度上缓解了过拟合。
  • 缺点：神经元死亡问题。如果输入为负，梯度为 0。如果一个神经元在训练过程中因为较大的负梯度更新，导致它的权重在随后的数据中总是输出负数，那么这个神经元将永远不会被激活，它的参数也不会再更新。
import torch.nn as nn
relu = nn.ReLU()

Leaky ReLU

Leaky ReLU 是为了解决 ReLU 的神经元死亡问题而提出的改进版本。𝛼 是一个很小的常数。

$$f(x) = \begin{cases} x & x \ge 0 \\ \alpha x & x < 0 \end{cases}$$
  • 输出范围 (−∞, +∞)。
  • 优点：保留了 ReLU 的所有优点，同时在 𝑥 < 0 时赋予了一个非零的微小梯度（𝛼），确保神经元即使在输入为负的情况下也能有微小的参数更新，解决了 Dead ReLU 问题。
  • 缺点：实践中，普通的 ReLU 往往已经足够好用，Leaky ReLU 带来的提升有时并不显著。
import torch.nn as nn
# negative_slope 对应公式中的 alpha，默认为 0.01
leaky_relu = nn.LeakyReLU(negative_slope=0.01)

PReLU

PReLU 是 Leaky ReLU 的推广，它将负半轴的斜率设为可学习的参数。

$$f(x) = \max(0, x) + a \cdot \min(0, x)$$
  • 参数 𝑎 随着网络训练自动调整。
  • 优点：增加了模型的灵活性，能够自适应地学习负区间的特征，减少了人工调参的压力。
import torch.nn as nn
prelu = nn.PReLU()

ELU

$$f(x) = \begin{cases} x & x \ge 0 \\ e^{x}-1 & x < 0 \end{cases}$$
  • 优点：在负值区域具有平滑的饱和特性，使得输出均值更接近 0。相比 ReLU，它能更快地收敛并获得更好的泛化性能。
import torch.nn as nn
elu = nn.ELU()

SELU

  • 特点：在特定条件下（配合 LeCun 初始化），SELU 能够实现自归一化，使每一层神经元的激活值自动保持均值 0 和方差 1。
  • 适用：非常适合极深的稠密全连接网络，也就是自归一化网络。
import torch.nn as nn
selu = nn.SELU()

Softplus

$$f(x) = \ln(1+e^{x})$$
  • 特点：ReLU 的全定义域可导光滑版本。虽然计算量略大，但在一些需要高阶导数平滑性的物理建模或生成模型中表现良好。
import torch.nn as nn
softplus = nn.Softplus()

GELU

  • 原理：引入了概率思想，根据输入的值按高斯分布随机决定是否激活。
  • 地位：它是 BERT、GPT 和 Vision Transformer（ViT）等主流 Transformer 架构的默认标配。
import torch.nn as nn
gelu = nn.GELU()

Swish / SiLU

$$f(x) = x \cdot \mathrm{Sigmoid}(x)$$
  • 特点：具备无上界、有下界、平滑、非单调的特性。
  • 应用：由 Google 提出，是 EfficientNet 和 YOLO 系列的灵魂组件。
import torch.nn as nn
silu = nn.SiLU()

Mish

$$f(x) = x \cdot \tanh(\mathrm{Softplus}(x))$$
  • 特点：被认为比 Swish 更加平滑。在很多视觉公开基准测试中，Mish 的表现略优于 ReLU 和 Swish，但计算成本也稍高。
import torch.nn as nn
mish = nn.Mish()

Hard Swish

Hard Swish（H-Swish）是 MobileNetV3 的核心优化点。它在保留 Swish 性能的同时，大幅提升了推理速度。

$$f(x) = \frac{x \cdot \mathrm{ReLU6}(x+3)}{6}$$ 
import torch.nn as nn
hardswish = nn.Hardswish()
